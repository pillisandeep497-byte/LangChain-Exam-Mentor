# LangChain Exam Mentor

An AI-powered Exam Preparation Assistant built using:

- LangChain
- Google Gemini
- Pydantic Output Parser
- Chat Memory

## Features

✅ Detailed Definitions

✅ Important Keywords

✅ Exam Writing Format

✅ 2 Marks, 4 Marks, and 8 Marks Answers

✅ Important Bullet Points

✅ Quick Revision Notes

✅ Conversation Memory

## Tech Stack

- Python
- LangChain
- Gemini 3.6 Flash
- Pydantic
- dotenv

## Installation

```bash
git clone https://github.com/yourusername/LangChain-Exam-Mentor.git

cd LangChain-Exam-Mentor

pip install -r requirements.txt
```

Create a `.env` file

```env
GOOGLE_API_KEY=your_api_key
```

Run

```bash
python app.py
```
